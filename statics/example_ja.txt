:::# 段落

通常のテキスト行は段落になります。
複数の連続する行は、改行で結合されて一つの段落になります。

---

:::# 明示的な段落（ParaBlock）

: `: ` で始まる段落はメタデータ修飾子を受け付けます。
@[class: lead]

---

:::# 混合してネスト可能な箇条書きリストと番号付きリスト

  - メモ B

  - メモ C

- 親 A
  # サブステップ 1
  # サブステップ 2
- 親 B

:::# タスクリスト

[x] 完了したタスク
[ ] 未完了のタスク
[x] 別の完了したタスク

---

:::# 定義リスト

: 定義ブロックは `:= 用語` で始まり、次の行に本文段落を記述します。

:= 決定論的
パーサーは、同じ入力が常に同じ出力を生成し、曖昧さがない場合に決定論的といいます。

:= 単一パス
処理は一方向に一行ずつ進み、先読みやバックトラックを行いません。

---

:::# カジュアル定義リスト

リストの文脈では `? 用語` と `= 説明` で簡易的な定義リストを作成できます:

? 決定論的
= 同じ入力が常に同じ出力を生成し、曖昧さがない。
? 単一パス
= 先読みやバックトラックなしに、一行ずつ一方向に処理を進める。

---

:::# ブロック引用

> 単一行のブロック引用。

|>
複数行のブロック引用。
**インラインマークアップ**も引用内で使用できます。

空行を挟むとブロック内で新しい段落が始まります。
<|
@[author: 著者名]
@[cite: 出典タイトル]

:::# JavaScript ブロック（ハイライトデモ）

#!javascript
// フィボナッチ数列（反復処理）
function fibonacci(n) {
  let a = 0, b = 1;
  for (let i = 0; i < n; i++) [a, b] = [b, a + b];
  return a;
}

const results = Array.from({ length: 8 }, (_, i) => fibonacci(i));
console.log('フィボナッチ:', results.join(', '));
!#
@[title: JavaScript 構文ハイライト]

---

:::# Python ブロック（ハイライトデモ）

#!/usr/bin/env python3
# フィボナッチ数列（反復処理）
def fibonacci(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

results = [fibonacci(i) for i in range(8)]
print('フィボナッチ:', ', '.join(map(str, results)))
!#
@[title: Python 構文ハイライト]
