:: 段落

通常のテキスト行は段落になります。
複数の連続する行は、改行で結合されて一つの段落になります。

:: 定義リスト

:= 決定論的
パーサーは、同じ入力が常に同じ出力を生成し、曖昧さがない場合に決定論的といいます。

:= 単一パス
処理は一方向に一行ずつ進み、先読みやバックトラックを行いません。

:: JavaScript ブロック（ハイライトデモ）

#!javascript
// フィボナッチ数列（反復処理）
function fibonacci(n) {
  let a = 0, b = 1;
  for (let i = 0; i < n; i++) [a, b] = [b, a + b];
  return a;
}

const results = Array.from({ length: 8 }, (_, i) => fibonacci(i));
console.log('フィボナッチ:', results.join(', '));
!#
@[title: JavaScript 構文ハイライト]

:: Python ブロック（ハイライトデモ）

#!python
# フィボナッチ数列（反復処理）
def fibonacci(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

results = [fibonacci(i) for i in range(8)]
print('フィボナッチ:', ', '.join(map(str, results)))
!#
@[title: Python 構文ハイライト]
