:::# Definition List

: A definition block starts with `:= Term` followed by a body paragraph on the next line.

:= Deterministic
A parser is deterministic when the same input always produces the same output with no ambiguity.

:= Single-pass
Processing proceeds line by line in one forward pass — no lookahead or backtracking.

---

:::# Casual Definition List

In list context, use `? Term` and `= Description` for lightweight definition pairs:

? Deterministic
= Same input always produces the same output with no ambiguity.
? Single-pass
= Processing proceeds line by line with no lookahead or backtracking.

:::# URL Autolinks

A standalone HTTPS URL becomes an autolink; the visible label is derived from the hostname.

https://www.wikipedia.org/

Image extensions (`.jpg`, `.png`, etc.) are also just autolinks — to embed external images, use ExternalEmbed.

https://picsum.photos/seed/blogable1/600/200.jpg

---

:::# ExternalEmbed

Use `!!URL|alt!!` to embed an external image, video, or link as a block.
A space is also accepted as a separator: `!!URL alt!!`

Image:
!!https://picsum.photos/seed/blogable1/600/200.jpg|Sample photo!!
@[title: External image via ExternalEmbed]

Inline usage always renders as an external link, regardless of media type:

See !!https://example.com|this site!! for more info.

---

:::# ObsidianEmbed (Local Image)

Use `![[path]]` or `![[path|alt]]` to embed a local image file as a figure:

![[statics/IMG_0698.png|Blogable logo]]

:::# JavaScript Block (highlight demo)

#!javascript
// Fibonacci sequence (iterative)
function fibonacci(n) {
  let a = 0, b = 1;
  for (let i = 0; i < n; i++) [a, b] = [b, a + b];
  return a;
}

const results = Array.from({ length: 8 }, (_, i) => fibonacci(i));
console.log('Fibonacci:', results.join(', '));
!#
@[title: JavaScript syntax highlight]

:::# Python Block (highlight demo)

#!/usr/bin/env python3
# Fibonacci sequence (iterative)
def fibonacci(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

results = [fibonacci(i) for i in range(8)]
print('Fibonacci:', ', '.join(map(str, results)))
!#
@[title: Python syntax highlight]
